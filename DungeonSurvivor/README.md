# DungeonSurvivor

Este proyecto ya está listo para ser servido como página web estática.

## Cómo usarlo

### Localmente
1. Abre una terminal en esta carpeta.
2. Ejecuta:

```bash
python -m http.server 8000
```

3. Abre en tu navegador:

```text
http://localhost:8000
```

### Compartir por URL
Puedes subir esta carpeta a un hosting estático como:
- GitHub Pages
- Netlify
- Vercel
- Surge

Asegúrate de que el archivo se llame `index.html` en la raíz del sitio.

## Archivo principal
- `index.html` — el juego completo listo para jugar desde el navegador.
